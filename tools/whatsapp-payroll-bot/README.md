# Shree RR Trading Company - 100% Anti-Ban WhatsApp PDF Auto-Dispatcher

## 🌟 Introduction (Ye Kya Hai?)
Ye ek **Zero-Click 100% Anti-Ban Safe WhatsApp PDF Auto-Dispatcher** hai jo **Shree RR Trading Company** ke workers ko unki official stamped salary slip ka **asli `.pdf` document** unke WhatsApp chat me bhejta hai.

Isme worker ko koi link nahi milti — unke WhatsApp chat me sidhe **asli PDF file (📄 Salary_Slip_August_2026.pdf)** aati hai jise wo 1 tap me khol sakte hain.

---

## 🚀 Kaise Chalayein? (How to Run)

### Tareeqa 1: 1-Click Double Tap (Sabse Aasan)
1. Project ke main folder me jayein: `d:\project\shree_rr_trading_company`
2. Waha bani file **`START_WHATSAPP_AUTO_SENDER.bat`** par double click karein.
3. Browser me automatically **`http://localhost:3300`** khul jayega!

---

## 📱 WhatsApp Connect Kaise Karein?
1. Dashboard khulte hi screen par **QR Code** dikhega.
2. Apne phone me WhatsApp khole ➡️ Upar right me **3 Dots (Menu)** ➡️ **Linked Devices** par dabayein.
3. **Link a Device** dabakar computer screen par dikh rahe QR code ko scan karein.
4. Scan hote hi screen par **✅ WhatsApp Connected** dikh jayega.
*(Aapko ye sirf 1 baar karna hai. Baad me session yaad rehta hai).*

---

## ⚡ Slips Kaise Bhejein? (Zero-Click Auto Dispatch)
1. Dashboard me **Month** select karein (jaise `August 2026`).
2. **Anti-Ban Delay** select karein: `12 Seconds (Extra Safe - Recommended)`.
3. Button dabayein: **"Send All PDFs (Zero Click)"**.
4. Bot ek-ek karke sabhi workers ko unka **asli PDF document** unke mobile par deliver kar dega!
5. Aap chahe toh kisi ek worker ke aage **"View PDF"** dabakar uska PDF pehle dekh bhi sakte hain ya **"Send PDF"** dabakar single worker ko test bhej sakte hain.

---

## 🛡️ Anti-Ban Protection (Number Ban Se Suraksha)
Is tool me 3 special anti-ban safety features hain:
1. **Real WhatsApp Multi-Device Protocol:** Ye WhatsApp ke official linked device protocol par chalta hai.
2. **Human Composing Simulation:** PDF bhejne se pehle bot 2–3 second "Typing..." simulate karta hai.
3. **Smart Natural Delay:** Har worker ke beech 8 se 14 second ka random human-like delay leta hai taaki WhatsApp spam filter trigger na ho.
